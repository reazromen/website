Calling the nervous system a **communication network** is useful for about five minutes. The comparison can expose structure that ordinary language hides. The problem begins when the comparison stops behaving like a tool and starts behaving like a claim about what the thing literally is.

Networking language helps with topology, latency, propagation, synchronization and routing-like questions. It is especially useful for asking how local events influence a large connected system.

## What the metaphor gets right

Networking language helps with topology, latency, propagation, synchronization and routing-like questions. It is especially useful for asking how local events influence a large connected system.

This is why engineering metaphors are so attractive. They compress a complicated relationship into something we can manipulate mentally. In the best case, the metaphor produces predictions and sharper questions.

## What it smuggles in

A neural spike is not an Ethernet packet with a universal payload. Its significance depends on which neuron fired, when, and how the receiving network is currently configured.

Engineering words often carry hidden assumptions: a designer, a specification, modular ownership, explicit goals, a stable machine underneath the program. Those assumptions must be tested rather than inherited.

## Return to the physical story

Neurons maintain electrochemical gradients, generate action potentials and communicate through electrical and chemical synapses. Timing, connectivity, modulation, plasticity and circuit state all shape what a signal does.

Once the mechanism is back in view, the analogy can be kept on a short leash. We can state which relation is genuinely similar and which difference would make the analogy generate a wrong prediction.

## My three tests for a metaphor

1. **What mechanism does this comparison help me see?**
2. **Which engineering assumption does the natural system not share?**
3. **What would I predict incorrectly if I took the comparison literally?**

The third test is the most important. An analogy that cannot fail is decoration, not explanation.

## Beyond the borrowed language

Studies of biological electricity led from nerves and action potentials to circuit-level and computational neuroscience.

The nervous system blurs communication and computation because transmitting a signal can also modify the network that gives the signal meaning.

When does a network stop merely transmitting information and begin constructing a model of the world?

A good metaphor should eventually make itself less necessary. It gets us close enough to the real system that we can see where the scaffolding ends.
