When two variables move together, the mind wants an arrow.

A rises, B rises.

Therefore A causes B.

The arrow feels almost visible.

But correlation does not contain an arrow. It contains a relationship in observations.

That relationship can be extremely useful. It can predict, diagnose, and point toward mechanism. It simply does not identify the mechanism by itself.

## Common causes create associations

Suppose two measurements rise during hotter days.

One might be electricity use. Another might be the temperature inside equipment.

Neither has to cause the other directly. Outdoor temperature can influence both.

That is confounding: another variable helps generate the association.

Reverse direction is another possibility. We may infer that A drives B when B actually affects A.

Selection can create a third problem. The way observations enter a dataset can generate an association absent from the wider system.

These are not rare philosophical loopholes.

They are ordinary causal structures.

## Correlation can still be valuable

The slogan correlation is not causation is sometimes used too aggressively.

Correlation is often exactly where investigation begins.

If a failure rate is strongly associated with temperature, firmware version, or one hardware batch, that pattern can guide tests.

If two astronomical variables scale together, the relation can constrain physical models.

If one operational metric consistently moves before another, it may provide an early warning.

A clue is not worthless because it is not a mechanism.

The problem is promoting it too early.

## Intervention changes the question

A powerful route toward causal evidence is controlled intervention.

Change A while holding relevant alternatives as stable as possible.

Observe whether B changes as predicted.

Randomized experiments are powerful because random assignment helps break systematic links between an intervention and confounders.

But experiments are not always possible.

Observational sciences use natural experiments, longitudinal designs, causal models, and converging evidence from different sources.

Causal inference is a toolbox because nature rarely hands us perfect experiments.

## Time order helps but does not finish the job

A cause must usually precede its effect.

So if B consistently occurs before A, the claim that A caused B is weakened.

But temporal order alone is not enough.

Sunrise precedes peak solar output from a panel every day. Another variable—illumination—connects the two. Many processes share clocks without causing one another.

Sequence constrains the arrow.

It does not identify it uniquely.

## Mechanisms create new predictions

Suppose a correlation suggests that high temperature increases a device's error rate.

A mechanism might propose that a reference voltage drifts with temperature.

That hypothesis predicts more than the original correlation.

The reference should shift.

The error should change under controlled temperature.

Replacing the reference may alter the effect.

A circuit without the same dependence may behave differently.

Each prediction gives the causal story another chance to fail.

This is why mechanisms are so valuable.

They transform one association into a network of tests.

## Prediction can succeed without causal understanding

A model can predict outcomes using correlations without representing the true causal structure.

For some tasks, prediction is enough.

A classifier does not always need a complete explanation of why its input patterns occur.

But if we want to intervene—change a system, improve reliability, or design policy—causal structure matters.

Acting on a correlated variable can fail when that variable is only a proxy.

Prediction asks: what tends to happen next?

Causal inference asks: what would change if we changed this?

Those are different questions.

## The arrow has to be earned

Correlation compresses observations into a relationship.

Causation explains how changing one part of the system changes another.

The first can support the second.

It cannot simply become the second through confidence or repetition.

When two lines move together, treat the alignment as an invitation.

What other variables could produce it?

Which direction is plausible?

What intervention would separate the possibilities?

What mechanism predicts another effect?

Correlation is a clue.

A good clue is valuable because it tells us where to look next, not because it has already solved the case.
