DNA is called the source code of life so often that the metaphor begins to sound literal.

It is not.

The comparison is useful in one narrow sense: DNA contains sequences whose patterns influence the production of RNA and proteins, and some of those relationships can be represented symbolically. But cells do not boot a genome, execute instructions line by line, and produce an organism in the way a computer runs a program.

Biology is a chemical, historical, self-modifying system.

## Genes do not act alone

A protein-coding sequence matters because a cellular environment can transcribe, process, translate, fold, modify, transport, and regulate its products.

The same DNA sequence can behave differently in different cell types because different regulatory factors are present.

A neuron and a liver cell carry mostly the same genome yet implement radically different biological states.

If DNA were ordinary source code, the interpreter would have to be most of the cell.

At that point the metaphor has already admitted its own limit.

## Sequence is only one layer

Gene expression depends on promoters, enhancers, chromatin state, transcription factors, RNA processing, RNA stability, translation, protein turnover, localization, and many feedback loops.

Development adds another dimension.

A cell's current state depends partly on what happened before.

Signals received earlier can alter which genes become accessible later.

Biology therefore contains memory outside the raw nucleotide sequence.

The genome is necessary.

It is not a complete executable description of the organism.

## There is no clean separation between code and machine

Software architecture distinguishes program from hardware.

Cells blur that boundary.

Proteins encoded by genes help replicate DNA.

They regulate which genes are expressed.

They modify chromatin.

They build the membranes and structures that determine chemical context.

The system constructs and maintains parts of its own interpreter.

A genome without a compatible cell is not a self-starting machine.

DNA placed in the wrong biochemical context does not simply execute.

## Evolution does not refactor

Human code is usually written with goals.

Engineers remove duplication, rename variables, modularize, and replace obsolete components.

Evolution has no foresight.

New structures modify old ones.

Duplicated genes diverge.

Regulatory elements are co-opted.

Transposable elements leave history in the genome.

Function can emerge from arrangements no engineer would design from scratch.

This makes genomes look less like clean codebases and more like historically layered systems whose present architecture reflects survivable paths through the past.

## The metaphor fails hardest at meaning

In software, a symbol's meaning is assigned by formal conventions and implementation.

In biology, sequence function is often contextual.

The same motif can participate in different regulatory roles in different tissues.

A mutation can be neutral in one environment and consequential in another.

A protein can have multiple functions.

Non-coding regions can affect expression, chromosome structure, RNA production, or nothing detectable under current conditions.

Meaning is distributed across interaction.

## Information language still helps

Rejecting the source-code metaphor does not mean biology contains no information.

Sequence differences can be inherited.

Regulatory networks transmit signals.

Cells distinguish environmental states.

Genomes can be compared, compressed, aligned, and analyzed using information-theoretic ideas.

The mistake is assuming that because information is present, biology must work like software.

Information is a broader concept than computation as practiced by human machines.

## Better metaphors stay plural

DNA can be compared to a record of evolutionary history.

A parts catalogue.

A set of templates.

A regulatory substrate.

A heritable information store.

None is complete.

Using several metaphors prevents one from hardening into ontology.

DNA is not source code.

It is stranger and more interesting: a molecular archive embedded inside a living system that reads, modifies, copies, repairs, regulates, and evolves the very material that helps sustain that system.
