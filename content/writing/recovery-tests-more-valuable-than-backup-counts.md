Backup dashboards can create false confidence when success means only that a scheduled archive was written. The real requirement is restoring useful service state.

hserver DR work verifies checksums, archive formats, encrypted off-host copies and restore-oriented evidence instead of counting files. The Tor publishing platform backs up both database state and Onion identity because losing either changes what recovery means.

This is a DevOps culture lesson about outcome metrics. Measure the capability the business needs, not the easiest proxy generated by the tool.

Recovery confidence increases when the team repeatedly proves that saved state can become a functioning system again under realistic restore conditions.
