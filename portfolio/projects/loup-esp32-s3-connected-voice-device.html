BOUNDARIES / CONSTRAINTS

What the project does not pretend to solve.

—Real-time audio deadlines on ESP32-S3

—8 kHz telephony vs 16 kHz playback path

—Acoustic echo depends on physical enclosure and gain

—Firmware must remain manufacturer-independent

RESULT / CURRENT STATE

What this produced.

A working connected voice-device platform with stable two-way calling, a preserved firmware baseline, device lifecycle planning and a path toward production provisioning and OTA.
